# 03 — 实现云端认证、配对与持久化

**交付内容：** 管理员可以登录服务端、创建短时一次性配对码并绑定一台设备。服务端使用 SQLite 保存账户、设备、凭据状态、配对记录和审计事件；撤销设备凭据后必须重新配对。

**阻塞项：** 01 — 建立项目骨架与设备协议

**状态：** ready-for-agent

- [ ] SQLite Schema 和可重复执行的迁移可用
- [ ] 账号密码采用强哈希保存，登录会话安全且登录尝试受限
- [ ] 首个管理员账户通过受保护的服务端配置初始化，不写入仓库
- [ ] 配对码短时有效、只能使用一次，且不以明文写入日志
- [ ] 配对成功后生成独立设备凭据，浏览器/API 客户端不会获得该凭据
- [ ] 设备凭据可撤销，旧凭据撤销后请求失败
- [ ] 数据访问通过 Repository 接口，测试可替换存储实现
- [ ] 认证、配对、撤销和失败事件写入脱敏审计记录
- [ ] SQLite 文件位于持久化路径；权限、备份和恢复说明完成
