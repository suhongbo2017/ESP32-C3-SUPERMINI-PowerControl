# 06 — 实现签名 OTA 与恢复

**交付内容：** 管理员可以为已配对设备发布签名固件。设备完成签名、容量和版本校验后执行 OTA；首次启动健康检查失败时自动回滚。升级过程中不得触发电源脉冲。

**阻塞项：** 02 — 实现设备本地控制核心；03 — 实现云端认证、配对与持久化；05 — 接通设备 HTTPS 客户端与诊断链路

**状态：** ready-for-agent

- [ ] 4 MB 设备分区表包含两个可用 OTA 应用分区
- [ ] 固件签名、目标硬件、版本和镜像大小检查均有效
- [ ] OTA 下载失败、校验失败或中断不会破坏当前可启动固件
- [ ] 新固件首次启动执行健康确认；失败时自动回滚
- [ ] OTA 状态、失败原因和回滚事件同步到云端
- [ ] OTA 期间 GPIO1 保持安全低电平，且不接受电源脉冲
- [ ] 签名私钥不进入仓库，发布流程明确密钥使用边界
- [ ] USB 救援刷写以及回滚后的重新联网/认证流程有验证记录
