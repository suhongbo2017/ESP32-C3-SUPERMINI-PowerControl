# 05 — 接通设备 HTTPS 客户端与诊断链路

**交付内容：** 已配对设备可以通过 HTTPS 轮询服务端、领取并执行一次命令、上传回执和结构化诊断事件。网络故障恢复后不重放旧命令；本地控制始终独立可用。

**阻塞项：** 02 — 实现设备本地控制核心；03 — 实现云端认证、配对与持久化；04 — 实现云端命令服务

**状态：** ready-for-agent

- [ ] 设备使用 HTTPS 证书验证和独立设备凭据
- [ ] 在线轮询基线为 5 秒、心跳基线为 30 秒，并实现超时/退避策略
- [ ] 设备每次最多领取一条命令，验证 ID、有效期和命令类型后交给统一执行器
- [ ] 设备端对重复命令 ID 去重，不重复产生 GPIO 脉冲
- [ ] 执行结果回传，包含命令 ID 和脱敏错误信息
- [ ] 启动、配对、轮询、命令、Ping 和网络错误等关键事件直接同步云端
- [ ] 云端不可达时只使用有界 RAM 缓存，重启后允许丢失
- [ ] 云端可查询设备在线状态、Ping 可达性和诊断事件
- [ ] 端到端测试覆盖配对后轮询、命令执行、断网、重连和不重放
