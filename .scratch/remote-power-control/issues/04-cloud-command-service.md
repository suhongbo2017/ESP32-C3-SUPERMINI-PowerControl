# 04 — 实现云端命令服务

**交付内容：** 已认证的服务端调用者可以为已配对且在线的设备创建一次短按命令，并查询命令从 `rejected`、`claimed`、`executed`、`failed`、`expired` 到 `timed_out` 的生命周期。离线命令立即失败，不排队、不重放。

**阻塞项：** 01 — 建立项目骨架与设备协议；03 — 实现云端认证、配对与持久化

**状态：** ready-for-agent

- [ ] 在线状态可由协议模拟器/测试夹具驱动，在真实设备集成前验证服务
- [ ] 只有认证且获授权的服务端调用者可以创建命令
- [ ] 命令带唯一 ID、幂等键、创建时间和过期时间
- [ ] 设备离线时立即拒绝命令，不写入可执行队列
- [ ] 相同幂等请求不会导致两次物理动作
- [ ] 每次轮询最多领取一条未过期命令，并以原子方式标记为 `claimed`
- [ ] 过期、已领取和已完成的命令不会再次返回
- [ ] 执行回执只表达脉冲结果，不声称电脑已开机或关机
- [ ] 超时、拒绝、执行失败和重复请求均可查询
- [ ] 命令及审计事件写入 SQLite
- [ ] 服务测试覆盖离线、过期、并发领取、重试和去重
