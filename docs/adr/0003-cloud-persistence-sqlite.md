# ADR 0003：首版云端使用 SQLite

- 状态：已接受
- 日期：2026-10-20

## 背景

早期版本只面向单用户、单设备，并部署在现有单台主机上。当前实现已经支持多个管理用户和多设备数据模型，但仍部署在单台主机上；优先降低运维复杂度，而不是额外引入数据库服务。

## 决策

当前用户账户、设备配对、诊断快照和命令记录均持久化在 SQLite 中，通过仓储接口访问。

首版使用 SQLite 持久化。通过应用自有的仓储接口访问数据，并提供明确的数据库迁移。数据库存放在主机持久化存储中，不放在容器临时层。必须自动备份并实际演练恢复。

## 影响

- 无需单独部署和监控数据库服务。
- 必须明确处理备份、文件权限、事务、并发限制、磁盘空间耗尽等运维事项。
- 仓储接口应允许未来在扩展或可用性需求提高时迁移到服务器型数据库。
