# ADR 0001：项目隔离与任务跟踪方式

- 状态：已接受
- 日期：2026-10-20

## 背景

旧仓库混合了旧固件、ESPHome 配置、云端试验和部署说明。在原仓库内重构会使新旧行为、构建流程和发布流程耦合。

## 决策

在 `D:/PI/ESP32-C3-PC-POWER-NEXT` 建立独立 Git 仓库。将需要调查的旧资料复制到 `reference/`，仅供参考。使用 `.scratch/<功能名称>/` 下的 Local Markdown 管理规格和任务。部署时复用现有主机与域名，但隔离新服务配置和凭据。

## 影响

- 重构期间不改动旧项目的生产实现和回退实现。
- 新项目可独立设计代码、CI 和发布流程。
- 参考副本必须明确标记为非规范资料，并持续检查其中的密钥和环境专属标识。
- 生产部署隔离、切换和回滚仍需专门设计。
