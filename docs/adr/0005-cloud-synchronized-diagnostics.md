# ADR 0005：诊断日志同步到云端

- 状态：已接受
- 日期：2026-10-20

## 背景

远程设备需要具备故障排查能力，但把日志持久写入 Flash 会增加磨损和恢复复杂度。系统已经使用 HTTPS 连接设备与云端。

## 决策

设备通过 HTTPS 直接上传结构化、已脱敏的诊断事件。USB 串口提供实时日志。云端不可用时只保留有界的内存缓存，设备重启后允许丢失；首版不增加 Flash 日志队列。云端日志需认证后访问，不得包含密码、配对码、长期凭据或完整认证头。

## 影响

- 控制和诊断共用同一通信方式。
- 事件成功上传后可用于远程排障。
- 云端中断期间如发生掉电或重启，近期日志可能丢失。
- 必须定义并测试事件级别、格式、脱敏、限流、保留期限和查询授权。
