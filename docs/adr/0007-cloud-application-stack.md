# ADR 0007：模块化 Node.js 云端应用

- 状态：已接受
- 日期：2026-10-20

## 背景

首版需要 HTTPS API、手机端访问认证、SQLite 持久化、设备轮询、命令跟踪、诊断和 OTA 元数据，但不应引入分布式部署。

## 决策

云端使用 Node.js、TypeScript 和 Fastify，作为单一部署应用。内部按职责拆分模块，SQLite 通过仓储接口访问。首版不引入微服务或消息 Broker。

## 影响

- 单一运行时和部署单元更适合在现有主机上维护。
- TypeScript 和模块边界支持可测试的接口契约。
- API、认证、设备协议、数据持久化、诊断和升级管理仍需定义明确接口并做集成测试。
- Node.js 运行时和依赖的安全更新属于后续运维责任。
