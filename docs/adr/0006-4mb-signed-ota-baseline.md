# ADR 0006：4 MB 双分区签名 OTA 基线

- 状态：已接受
- 日期：2026-10-20

## 背景

设备需要支持远程维护；升级失败时不能让远程设备无法启动。SuperMini 闪存容量因批次而异，因此必须明确最低支持容量。

## 决策

至少支持 4 MB Flash 的设备。使用两个 OTA 应用分区、签名固件、升级前容量与目标检查、首次启动健康确认；健康检查失败时自动回滚。首版不支持 2 MB 设备。不预留大型文件系统或持久化日志队列。

## 影响

- 新固件启动失败时可自动恢复到上一可用固件。
- 固件和内嵌网页资源必须遵守严格体积预算。
- 签名密钥保管和 USB 救援仍是运维责任。
- 必须通过实际构建产物和硬件验证分区表及健康检查规则。
