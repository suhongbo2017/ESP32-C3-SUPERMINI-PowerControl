# ADR 0008：核心控制链路跑通后再做手机端

- 状态：已接受
- 日期：2026-10-20

## 背景

首要风险在 ESP32 控制链路和云端行为，而不在界面表现。先做手机 UI 可能掩盖配对、命令领取、执行回执、日志和恢复流程的问题。

## 决策

首个实现阶段不开发手机端 UI。先用 API 和测试客户端验证设备本地控制、服务端控制流程、HTTPS 轮询、命令状态、诊断事件和 OTA 元数据。核心接口端到端通过后，再开发手机端。

## 影响

- 首阶段实现范围更小，测试边界更清楚。
- 需要 API 测试客户端或最小服务端诊断入口支持验证。
- 后续手机端必须使用已稳定并测试过的认证 API，不得创建另一条控制链路。
